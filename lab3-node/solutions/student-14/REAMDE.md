# SudokuGenBot (ВКонтакте)

Бот для игры в судоку во ВКонтакте: генерация головоломок трёх уровней сложности,
проверка ходов по строке/столбцу/блоку, автоматическое определение победы и учёт
времени прохождения.

---

## ✨ Возможности

- 🧩 Генерация судоку трёх уровней сложности: **лёгкая**, **средняя**, **сложная**.
- 🎯 Проверка корректности каждого хода (строка, столбец, блок 3×3, неизменяемость
  изначально заданных клеток).
- ✅ Команда `/check` — полная проверка решения с указанием ошибочных клеток.
- ⏱️ Замер времени прохождения и сохранение статистики по завершённой партии.
- 👥 Независимые игровые сессии для каждого пользователя.
- 🔄 Конечный автомат состояний: `IDLE`, `PLAYING`, `SOLVED`.
- 🛡️ Валидация входящих команд — бот не падает при некорректных запросах.
